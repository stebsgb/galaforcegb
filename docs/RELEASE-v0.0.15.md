# Galaforce for Game Boy v0.0.15

Build: `galaforce-0.0.15.gb` (MBC1 + RAM + battery, 32 KB ROM).

## Fixes
- Smart bomb: the smart bomb addition is fixed. It is no longer reset when you lose a life, so a bomb you hold stays with you. A bomb is added only when the boss is killed (up to 2 held).

## Changes
- Boss: the boss now has additional explosion hits. Each bullet hit on the boss shows a full explosion with its sound, and during the last 5 hits explosions appear one at a time over the boss.
