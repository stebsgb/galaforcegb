# Galaforce for Game Boy v1.0.5

Build: `galaforce-1.0.5.gb` (MBC1 + RAM + battery, 32 KB ROM).

## Changes
- **Boss level completion:** Defeating the boss ends the level after its death animation; the remaining blocker aliens no longer need to be defeated.
- **Boss low-health descent:** When the boss reaches its final three hits, it begins a crash descent
